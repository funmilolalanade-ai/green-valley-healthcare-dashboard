📊 Green Valley Medical Center Dashboard
🏥 Project Overview

This project analyzes hospital patient data to evaluate recovery outcomes, treatment costs, hospital stay duration, and departmental performance using Microsoft Excel.

🎯 Objectives
Analyze patient recovery outcomes
Evaluate departmental performance
Assess treatment cost efficiency
Explore demographic impact
Build an interactive dashboard
📊 Dashboard Features
KPI Cards (Recovery, Cost, Stay Duration)
Department Performance Analysis
Treatment Cost Comparison
Doctor Performance Insights
Interactive Filters (Slicers)
📈 Key Insights
Higher treatment cost does not always lead to better recovery
Longer hospital stays do not guarantee improved outcomes
Performance varies significantly across departments and doctors
Certain treatments provide better outcomes at lower cost
💡 Recommendations
Standardize best-performing departments
Optimize treatment costs
Reduce unnecessary hospital stays
Monitor doctor performance
📊 Tools Used
Microsoft Excel
Pivot Tables
Data Visualization
🚀 Future Improvements

This dashboard and analysis framework can be extended into Power BI for real-time hospital performance monitoring and predictive analytics.
